# 風格：暗色科技風

| 項目 | 內容 |
|---|---|
| 適用範圍 | 選了「暗色科技風」的短片。給 Agent 讀：做畫面、字幕、動畫時照「固定的規則」；遇到「和使用者討論」的項目，先提建議再讓使用者決定 |
| 相關文件 | 製作流程：[科普短片.md](科普短片.md)<br>交片前的檢查：[品質檢查表.md](品質檢查表.md) |
| 狀態 | 第一版，2026-11-03 |

這份只管「看起來、聽起來的樣子」。內容的規矩（例如每句要有出處、說明動畫一定要標「示意圖」）寫在主題文件，不管選哪種風格都要遵守。

## 固定的規則

尺寸以 1080×1920 的直式畫面為準。字型一律用 Noto Sans CJK TC；電腦上沒有這個字型時，先問使用者，不要自己換。

| 項目 | 規則 |
|---|---|
| 頂部標題 | 整支片固定一行，離頂部 90；白色、字重 900、字級 52；重點字用紅色 `#ff5a3c`；加黑色陰影 |
| 字幕 | 放在離底部 200 的位置，置中。中文：黃色 `#ffd43b`、字重 900、字級最大 58，句子太長就縮小字級，保持一行。第二語言（有的話）：白色、字重 700、字級 36，放在中文下方。都加黑色陰影 |
| B-roll（配合旁白的輔助畫面）版面 | 橫式影片寬度撐滿，放在畫面中間（離頂部 560）；背景用同一段影片放大 1.15 倍、模糊、亮度調到 45%，填滿上下空白 |
| 說明動畫的底色 | 由中間往外的暗色漸層：`#1c2129` → `#0b0d10` |
| 說明動畫的重點色 | 只用 4 個：紅 `#ff5a3c`、青 `#7fd8ff`、琥珀 `#ffb340`、綠 `#5be08a`；線條和次要文字用灰 `#c9d1db`、`#8a93a0` |
| 說明動畫的標題 | 小標灰色 `#aab3bf`、字級 40；大標白色、字重 900、字級 90，重點字用紅色 |
| 「示意圖」標籤的樣子 | 放在動畫標題正下方：灰色細框（`#8a93a0`、圓角 8）、灰字 `#c9d1db`、字級 30，文字「示意圖・非實際設計」 |
| 數字卡 | 一個大數字加一行說明，例如「600 L／加起來六百公升」；大數字用重點色 |

## 和使用者討論的項目

每一項都先依照現在短影音、科普影片常見的做法提出建議，**附上理由**，再讓使用者決定。建議是 Agent 根據剪輯慣例提出的，沒有經過實測，所以理由要寫清楚，使用者才能判斷。

| 項目 | 要問什麼 | 建議的例子 |
|---|---|---|
| 頂部標題 | 先提 3 個標題，每個附一句理由。使用者不滿意就再想 3 個；想微調其中一個，就一起改 | 「〇〇〇：XXX 為什麼會 YYY」：用問題勾起好奇 |
| 口吻 | 這個風格預設「用提問帶出內容、口語短句、偶爾小吐槽」，問使用者要不要照用、要改哪裡（例如不要吐槽） | 預設口吻的句子：「我好奇的是：一台車，到底借了什麼，才飛得起來？」 |
| 字幕語言 | 只要中文，還是中文加第二語言？取決於觀眾是誰 | 要放上國際平台就加英文 |
| 講者 | 要不要講者？要的話，是誰、長什麼樣子、什麼時候出現？ | 只在開場、段落轉換、結尾出現，中間用畫面講解，觀眾比較不會膩 |
| 配音 | 用哪一類聲音？語速多快？ | — |
| 沒有講者時的畫面安排 | 開場、轉場、結尾放什麼？ | 開場放最吸睛的 B-roll 加標題 |

## 範例：Roadster 發表會解說短片

開發時做的範例，用來看這個風格實際長什麼樣子，不是給使用者的選項。成品 2 分 26 秒，中英雙語字幕。

- **講者**：AI 生成的角色「外星觀察員」，只在開場、段落轉換、結尾出現
- **口吻**：好奇的外星學者，從「觀察地球人」的角度講，內容正經、偶爾小吐槽。原句：
  - 「我觀察地球人很久了。」
  - 「我好奇的是：一台車，到底借了什麼，才飛得起來？」
  - 「最後一樣，跟火箭無關。」
  - 「但地球人做它，不是為了倒吊。」
- **配音**：加速 1.1 倍
- **頂部標題**：「外星人拆解：Roadster 為什麼會飛」
