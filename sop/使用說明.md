# 用 video-use 做科普短片

| 項目 | 內容 |
|---|---|
| 適用範圍 | 想把科學、科技類的影片做成短片的人，不需要會寫程式 |
| 相關文件 | 安裝：[README.md](../README.md) 的「Setup prompt」<br>Agent 照著做的流程：[科普短片.md](科普短片.md) |
| 狀態 | 第一版，2026-11-04。目前做到分鏡表（每句旁白配什麼畫面的表），成品影片之後才做得出來 |

## 這是什麼

你給素材（發表會、講座、訪談、官方影片），說一句「做一支科普短片」，Claude 會幫你做出約 2 分半的直式短片：讀完素材、挑主題、寫稿、配畫面。你只要在 4 個地方回答它，其他都用預設值做。

## 要準備什麼

- **Claude Code**：在電腦上跟 Claude 對話、讓它幫你操作的工具。要 Claude 的付費方案（Pro 以上），免費方案不能用（2026-11-04 查官網）。安裝方式見[官網](https://code.claude.com/docs/en/setup)。
- **這個 skill**：skill 是給 Claude 的說明書和工具。打開 Claude Code，把 README 的「Setup prompt」那段話貼給它，它會自己安裝。
- **ElevenLabs 帳號**：把影片的聲音轉成文字、做配音都會用到。免費方案每個月 10,000 點；轉錄 1 分鐘約 330 點，所以大約能轉 30 分鐘的影片（2026-11-04 查官網）。免費方案不能用程式呼叫「聲音市集」裡的聲音，配音要到 ElevenLabs 網站自己生成（2026-10 實測）。要公開發布的影片，先確認你的方案能不能商用。

**會花額度的步驟**：轉錄、配音、生成講者。Claude 做這幾件事之前一定會先問你。

## 怎麼開始

1. 開一個新資料夾，把影片放進去；有逐字稿的話也一起放。一支片用一個資料夾，不同的片混在一起，檔案會互相覆蓋。
2. 打開終端機（輸入指令的視窗；Windows 用 Git Bash 或 PowerShell，Mac 用「終端機」），執行：
   ```bash
   cd 你的資料夾路徑   # 進到放影片的資料夾
   claude              # 打開 Claude Code
   ```
3. 跟它說：「做一支科普短片」。可以多加一句偏好，例如「講給國中生聽」。

只有網址、還沒下載影片的話，直接把網址給它，它會幫你下載影片和字幕。偶爾 YouTube 會擋下來，這時它會請你自己下載。

## 你會被問 4 次

| 什麼時候 | 你會看到 | 你要回什麼 |
|---|---|---|
| 1 開始 | 它找到的素材清單 | 有沒有漏；沒有逐字稿時，回答要怎麼取得 |
| 2 讀完素材 | 企劃：主題、標題、大綱、風格 | 沒意見就回「好」，會照推薦的做；想換就說換哪一項。**要不要講者、用哪個配音聲音一定要另外回答** |
| 3 寫完稿子 | 稿子和分鏡表 | 「好」，或指出要改的句子、畫面 |
| 4 成品（之後） | 成品影片和品質檢查的結果 | 「好」，或提修改意見 |

## 做完拿到什麼

都放在影片資料夾裡的 `edit/`：

- `內容目錄.md`：素材每一段在講什麼、從第幾分鐘到第幾分鐘
- `企劃.md`：你在第 2 次確認的內容
- `稿子.md`：旁白稿，每句都附出處（原片第幾秒）
- `分鏡表.md`：每句旁白配什麼畫面
