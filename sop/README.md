## SOP 和 recipe 的分法

| | SOP（`sop/`） | recipe（`recipes/`） |
|---|---|---|
| 是什麼 | **一條產品線**：做出某一種片 | **一份經驗**：碰到某種素材或手法時怎麼處理 |
| 單位 | 類型 × 格式，例如「科普短片」「新聞短片」 | 素材或手法，例如「長訪談整理」「上下分鏡」「新聞取捨」 |
| 內容 | 步驟、確認點、每一步交出什麼、預設值、交片檢查 | 做法、預設（要先問使用者）、踩過的坑、範例 |
| Agent 怎麼用 | 照做，只在確認點停下來 | 提出剪輯策略前讀，預設要先問過使用者 |
| 誰引用誰 | SOP 可以引用 recipe | recipe 不引用 SOP，可以被好幾條產品線共用 |
| 判斷方式 | 回答得出「做完交出什麼」 | 回答得出「碰到這個狀況怎麼辦」 |

一份文件同時有兩種內容時拆開：步驟和確認點放 SOP，經驗放 recipe。

## 一份 SOP 要寫什麼

1. 開頭表格：適用範圍、相關文件、狀態。
2. 怎麼帶使用者：在哪幾個確認點停、每個確認點給什麼看。
3. 步驟：每一步「做什麼、交出什麼、怎麼檢查」。
4. 預設風格：寫風格名稱，不寫顏色和字級（那些在風格層）。
5. 交片檢查。

寫好之後在 `SKILL.md` 的 SOPs 段落加一行，Agent 才找得到。
