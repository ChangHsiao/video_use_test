# 風格：暗色科技風_橫式（暫定）

| 項目 | 內容 |
|---|---|
| 適用範圍 | 橫式 1920×1080 的長影片（例如 10～15 分鐘的觀念介紹片）。給 Agent 讀 |
| 給程式讀的數值 | `style.json`（版型 `broll_wide`，由 `helpers/compose.py` 畫字幕和標題） |
| 狀態 | 2026-11-25 暫定版：顏色照暗色科技風，位置和字級是暫定值，等長影片的風格文件定案再調 |

## 目前的規則

- 除了畫面尺寸、文字位置和字級，其他規則（顏色、重點色、段落標題卡、數字卡、「示意圖」標籤）都照[暗色科技風](../暗色科技風/STYLE.md)。
- 直式素材放在畫面中間，左右用同一個畫面放大、模糊、調暗補滿；橫式素材鋪滿。
- 還不支援品牌 logo 和吉祥物：`style.json` 寫了 `logo` 或 `mascot`，載入時就會報錯。

使用方式：`合成.json` 寫 `"style": "暗色科技風_橫式"`。
