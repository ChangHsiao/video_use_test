# 旁白聲音規格：頂級 YouTube 工作室

前提：

- **錄音間：** 經過聲學處理，殘響時間 RT60 < 0.3 秒，空調與電腦不在錄音間內。
- **器材：** 大振膜電容麥克風或 SM7B 類動圈麥克風，加防震架與防噴罩，嘴巴距離麥克風 8–12 cm。
- **前級與介面：** 乾淨的前級，24-bit / 48 kHz。
- **後製：** 由專業團隊處理，例如 iZotope RX 降噪、去唇齒音、換氣控制，再加上 EQ、壓縮與母帶處理。

以下規格是「成品聽起來應該長這樣」，不是「器材要買什麼」。我們用 TTS 加後製去模擬出這個結果。

| 項目 | 規格 | 理由與依據 |
|---|---|---|
| 整體響度 | −16 LUFS（±1） | Apple Podcasts 建議值；YouTube 會把響度正規化到 −14 LUFS，留 2 dB 不會被壓 |
| 真峰值 | ≤ −1.0 dBTP | 避免轉檔後破音 |
| 響度起伏（LRA） | 3–6 LU | 有起伏但不忽大忽小。純旁白的 podcast 一般落在這個範圍 |
| 底噪（停頓時） | ≤ −65 dBFS（RMS） | ACX 有聲書的上限是 −60；頂級錄音間在 −70 左右。底噪不該是數位全靜音，否則停頓會顯得「斷掉」 |
| 換氣聲 | 比說話低 24–30 dB（以最大聲的那一次計），每次 ≤ 0.35 秒，每分鐘 3–9 次 | 實測校正：上一版換氣只比說話低 13–18 dB、長 0.6 秒，你聽起來太大聲。專業後製通常把換氣壓低 6–12 dB，不會整個刪掉 |
| 換氣的位置 | 只在句號、問號，或較長的逗號停頓之前 | 真人只會在意群之間換氣 |
| 唇齒音、嘴巴雜音 | 聽不到 | 後製會用 De-click 處理 |
| 齒音（ㄙ、ㄘ、ㄕ） | 5–9 kHz 壓 3–6 dB | 清楚但不刺耳 |
| 噴麥、低頻 | 75 Hz 以下切除 | 等於防震架加高通濾波 |
| 音色 EQ | 250–350 Hz 削 1.5–2 dB（減混濁）、4 kHz +1.5 dB（咬字清楚）、10 kHz 以上 +1.5 dB（空氣感） | 常見的人聲後製曲線 |
| 動態處理 | 兩段式：輕壓縮 2:1（壓 2–4 dB，保留句與句的大小聲差），再用快速壓縮或限幅接住峰值 | 讓聲音「貼耳」、穩定 |
| 空間感 | 乾聲、沒有殘響 | 近距離錄音的親密感 |
| 節奏 | 沿用韻律處理：關鍵句放慢、鋪陳句加快，停頓依標點分級 | 見 `prosody.py` |

## 跟上一版比改了什麼

1. **不再用 [inhales] 標籤**，那就是刻意感的來源。只保留模型自然產生的換氣，並且依照上表的位置規則篩選。
2. **換氣處理：** 換氣聲取自同一個聲音先前的錄音（換氣素材庫），只放在句子之間；比說話低約 25–30 dB，長度最多 0.32 秒，開頭淡入 80 ms。
3. **底噪：** 約 −71 dBFS。
4. **後製鏈：** 改成上表的錄音室規格。
5. **驗收：** 每個成品都用 `tools/vocal_qc.py` 量測，逐項對照上表。
