# 短影音包裝系統：片尾、封面、標題

這份文件整理三件事：研究結論、片尾三種風格、封面與標題三套系統。所有選項都套用 CIS：桑尼資料科學的配色、字體，以及「專業、數據驅動、不販賣焦慮」的調性。

## 一、研究結論（中、美專家與數據）

證據分三級：

- **官方**：平台公布的規則。
- **數據**：統計或實驗，大多只是相關性，不能證明因果。
- **經驗談**：創作者自述，證據最弱。

| 結論 | 證據 | 來源 |
|---|---|---|
| Shorts 在主 feed 是自動播放的，觀眾先看到的是**第一幀**，不是封面。封面主要出現在頻道頁、搜尋和訂閱頁 | 官方規則＋推論 | YouTube Help；Shorts 封面上傳功能 2026-07 起分批開放 |
| 所以**第一幀要直接做成封面**：一張圖同時當 hook 和封面 | 中美兩份研究的共同建議 | — |
| 封面字要少，一眼看完。英文建議約 5 個字；中文換算約 6–12 字，最多兩行 | 數據（vidIQ 500 張；1of10 30 萬支，兩者部分矛盾） | vidIQ、1of10 |
| 有沒有臉影響不大。財經類放臉有利，商業類反而不利 | 數據（1of10） | — |
| 青色系、亮度高的封面平均觀看較高 | 數據（1of10，相關性）。剛好是我們的品牌主色 | — |
| 標題帶負面事實（下台、調查）點擊較高，但「恐懼」類詞會降低點擊 | 數據（Upworthy 10.5 萬組隨機對照實驗） | Robertson 2023 |
| **問句標題觀感最差**。「說明句＋一個未知點」比加問號安全 | 數據（實驗） | Engaging News Project 2016 |
| 中文標題用數字、醒目標點有幫助 | 數據 | AJIM 2019 |
| YouTube 的封面 A/B 測試比的是**觀看時長**，不是點擊率。標題黨會輸 | 官方 | Rene Ritchie |
| **Shorts 片尾不宜長**。觀看時重播也算觀看，長片尾會讓人滑走、打斷循環。中國方面建議完全不做片尾卡，美國方面建議 3–5 秒、用「價值型」行動呼籲 | 官方（重播計觀看）＋經驗談 | YouTube、vidIQ、中國營運文章 |
| 不要說「記得訂閱」，改說能得到什麼，例如「每週用數據看懂一則科技大事」；或改成邀請留言 | 經驗談（中美一致） | — |
| Shorts 沒有片尾畫面。可以用「相關影片」連結接到長片或下一集 | 官方 | YouTube Help |
| 安全區：上方約 15%、下方約 20%、右側約 140px 會被 UI 遮住 | 第三方規格工具，各家數字不一 | — |

**結論：**

- 片尾要短，行動呼籲要講價值。
- 封面等於第一幀，大字 6–12 字。
- 標題用「事實＋一個未知」，不用問號、不用驚嚇字眼。

## 二、片尾三種風格

三種都是 4 秒，可以再縮到 3 秒。Logo 改用向量重繪，有自己的動畫，不再是一張貼圖。檔案在 `animations/out/O1–O3.mp4`。

| | A 數據流 | B 新聞台 | C 提問互動 |
|---|---|---|---|
| 動畫 | 青色點陣有一道數據波掃過，Logo 線條自己描繪、填色、點亮眼睛；名稱與英文字距展開；三個圖示依序畫出 | 紅色色塊擦過（接正片的紅擦），品牌角標「蓋章」進場，紅色編輯線延伸，跑馬燈 | 本集問題逐行浮現，關鍵詞用薄荷綠加紅底線，留言泡泡畫出，最後淡回黑色 |
| 標語 | 用數據，看懂科技大事。 | 科技新聞，拆給你看。 | 看懂新聞背後的數據 |
| 行動呼籲 | 追蹤／按讚／分享（線條圖示），加「每週拆解一則科技大事」 | 「下一集」預告卡，加「追蹤，不錯過下一集」 | 「留言告訴我們你的看法」，加「追蹤看下一集」 |
| 行銷邏輯 | 品牌識別最強，適合建立辨識度 | 用下一集製造追蹤理由，把單支觀看變成系列 | 互動權重高（留言＞按讚），又能循環播放，最符合研究結論 |
| 研究評估 | 片尾偏長，建議縮到 2.5 秒 | 下一集要真的有，否則就是承諾沒兌現 | **建議採用** |

原本的「不只學會，更要交付」是課程招生語，放在新聞短影音上會讓觀眾覺得在推銷。新的三句都改成講「這個頻道能給你什麼」：

- 用數據看懂
- 拆給你看
- 看懂背後

## 三、封面與標題三套系統

每套都包含四件事：封面（第一幀）、片中固定標題、YouTube 片名、說明欄第一行。範例以本集為例。檔案在 `design/cover_A–C.png`，比較圖是 `design/covers_compare.png`。

### A 人物＋關鍵詞（雜誌封面型，例如 WSJ、天下、財新）

- **封面**：
  - 照片：當事人新聞照，降低飽和度，暗部帶青色調。
  - 大字：兩行共 12 字以內，第一行 5 字，第二行的關鍵詞用薄荷綠。
  - 位置：放在畫面上 1/3，下方加一條短紅線。
  - 角標：左上角放品牌，底部放系列標籤。
- **片中固定標題**：`人物＋動作：關鍵詞`，例如「黃仁勳下台：私事變成國安疑雲」。
- **片名公式**：`人物＋事件：具體的未知｜桑尼資料科學`
  - 例：`黃仁勳下台：一段私事，怎麼變成國安疑雲｜桑尼資料科學`
- **適合**：有明確主角的事件。
- **風險**：照片授權。只用公司官方影像或可授權的照片，不用 Getty 這類圖庫。

### B 數據卡（數位時代、第一財經、Vox 型；最符合「數據驅動」）

- **封面**：
  - 數字：一個超大數字，例如「2 週」。
  - 說明：一行說數字的意義，再一行主題。
  - 背景：示意折線，人物照縮成圓形放在一旁輔助。
- **片中固定標題**：`數字＋主題`，例如「2 週：黃仁勳的國安疑雲」。
- **片名公式**：`數字＋事件＋含意｜桑尼資料科學`
  - 例：`2 週從報導到下台：黃仁勳的國安疑雲｜桑尼資料科學`
- **適合**：有可驗證數字的題目，例如股價、出口量、時間。
- **好處**：建立「看數字就知道是桑尼」的辨識度。

### C 系列問題卡（Axios、TLDR、志祺七七系列型）

- **封面**：
  - 色塊與底圖：品牌固定色塊，事件照片當淡底圖。
  - 系列條：頂部固定「科技大事 2 分鐘｜EP.01」。
  - 大字：三行，每行 4 字，最後一行用薄荷綠。
  - 下方：一行副標說明本集是什麼事件。
- **片中固定標題**：沿用三行大字，縮成一行。
- **片名公式**：`說明句（不加問號）＋事件｜系列名 EP`
  - 例：`一段私事怎麼變成國安疑雲：黃仁勳下台始末｜科技大事 2 分鐘 EP.01`
- **適合**：要做成系列、每週固定更新。
- **好處**：每集只換字，製作最快，頻道頁整齊。

### 三套共用的規則

- 封面就是影片第一幀。目前開場那 1.2 秒的封面卡，直接換成選定的版型。
- 大字只放在安全區內：y 300–1500、x 80–940。
- 一張圖只用一個重點色（薄荷綠），紅色只用在線條和標籤。
- 片名中文 15–25 字，關鍵詞放在前 10 字。片名問什麼，影片就要回答什麼。
- 不用「震驚」「快看」「再不看就」這類字眼（CIS 禁用），也不在片名用問號。

## 四、建議組合

- **片尾**：選 C（提問互動），縮到 3 秒，結尾接回開場，讓循環播放順暢。
- **封面與標題**：選 B（數據卡）當主系統。題材沒有好數字時，退回 C。

兩者都直接呼應品牌「數據驅動、不販賣焦慮」的定位，也有研究支持。
