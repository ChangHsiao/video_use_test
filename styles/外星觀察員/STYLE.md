# 風格：外星觀察員（暫定）

| 項目 | 內容 |
|---|---|
| 適用範圍 | 「外星觀察員」單元的工具介紹短片：外星主持人開場和收尾，中段放工具畫面（實錄或示意卡），直式 1080×1920 |
| 給程式讀的數值 | `style.json`（版型 `broll_top`，由 `helpers/compose.py` 畫字幕和標題） |
| 狀態 | 2026-11-22 試作用的暫定版。使用者要重新設計外觀，顏色、字級、版面之後會換掉 |

## 目前的規則

- 主持人：外星人角色（灰青膚色、琥珀眼、尖耳、粗花呢外套、圓形吊墜），坐在書房桌前正對鏡頭，胸口以上。角色和場景圖在影片資料夾的 `images/`。
- 主持人只出現在開場、轉折、收尾；中段放工具畫面。
- 工具畫面拿不到實錄時用示意卡，卡片右下角一定標「示意圖」和資料出處。
- 字幕用琥珀色（外星人眼睛的顏色），英文白字在下方。
- 配樂：開場比人聲低約 20 dB，全程墊底。
