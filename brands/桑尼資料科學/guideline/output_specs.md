### 印刷注意事項

- 所有印刷檔使用 **CMYK 色彩模式**
- 文字距裁切線至少 **5mm**（安全邊距）
- 黑色大面積使用 **Rich Black**：C60 M40 Y40 K100
- 細線最小 **0.25pt**
- 字體須**轉外框**或**嵌入 PDF**

## 五、輸出格式需求

### 每個設計物的標準交付格式

| 用途 | 必交格式 | 選交格式 | 備註 |
|------|---------|---------|------|
| **網路用途（社群/官網/EDM）** | PNG（透明背景）+ JPG | WebP | JPG 品質 85%+ |
| **印刷用途** | PDF/X-1a + AI（含出血與裁切線） | EPS | CMYK，字體轉外框 |
| **簡報** | PPTX + PDF | Keynote | |
| **Logo** | SVG + PNG（透明）+ AI | EPS | 多尺寸 PNG：64/128/256/512px |
| **原始可編輯檔** | AI / PSD / FIG | Canva 連結 | 圖層整理、命名清晰 |
| **動態素材** | MP4 (H.264) + GIF | MOV | 社群用 <15MB |

### 檔案命名規則

```
[品牌]_[類型]_[用途]_[尺寸]_[版本].[格式]

範例：
sunny_poster_ai-coding-workshop_A2_v1.pdf
sunny_ig-post_sprint-camp_1080x1350_v2.png
sunny_logo_horizontal_512px.svg
sunny_edm-header_march-campaign_600x200_v1.png
```

## 六、解析度需求

| 用途 | 解析度 | 色彩模式 | 備註 |
|------|--------|---------|------|
| **螢幕顯示（社群/官網/EDM）** | 72dpi（實際以像素尺寸為準） | sRGB | PNG/WebP 優先 |
| **一般印刷（名片/DM/海報 ≤ A2）** | 300dpi | CMYK | 必須含出血 |
| **大圖輸出（展架/看板 > A1）** | 150dpi | CMYK | 觀看距離遠，150dpi 足夠 |
| **Retina 螢幕** | 2x（尺寸 x 2） | sRGB | 例如 1080px 寬實際出 2160px |

### 實務換算參考

| 輸出物 | 成品尺寸 | 300dpi 所需像素 |
|--------|---------|----------------|
| 名片 90x54mm | 90 x 54mm | 1063 x 638px |
| A4 DM | 210 x 297mm | 2480 x 3508px |
| A2 海報 | 420 x 594mm | 4961 x 7016px |
| A1 海報 (150dpi) | 594 x 841mm | 3508 x 4967px |
