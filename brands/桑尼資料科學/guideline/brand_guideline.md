## 1. 品牌概述

### 品牌名稱

- **中文全稱**：桑尼資料科學
- **英文全稱**：Sunny Data Science
- **子品牌**：CIS (Capability Incubation System) — 能力孵化系統

### 一句話定位

> 以「作品交付驗收」為核心的 AI 時代人才培育系統。

### 品牌標語

> **不只學會，更要交付。**

### 核心價值觀

| 價值觀 | 一句話說明 |
|--------|-----------|
| **第一性原理** | 回歸問題本質，不被工具綁架 |
| **成果絕對導向** | 以可驗收的交付成果為唯一標準 |
| **與 AI 共同進化** | AI 是協作夥伴，不是依賴對象 |
| **極致務實** | 解決真實問題，拒絕空談理論 |

### 目標客群

| 類型 | 描述 |
|------|------|
| **主要** | 3-5 年經驗、希望用 AI 提升能力的工程師與產品經理 |
| **次要** | 轉職者、應屆畢業生、企業 AI 團隊 |

### 品牌性格

| 維度 | 我們是 | 我們不是 |
|------|--------|---------|
| 語氣 | 專業但親切 | 冷冰冰的企業腔 |
| 視覺 | 溫暖且乾淨 | 華麗花俏 |
| 態度 | 鼓勵嘗試、容錯 | 高高在上 |
| 內容 | 資訊密度高、數據驅動 | 販賣焦慮、空洞口號 |

## 2. Logo 使用規範

### 2.1 Logo 版本

| 版本 | 檔案 | 用途 |
|------|------|------|
| **橫式全彩** | `SUNNY_logo_wide.png` | 官網 header、簡報封面、橫式版位 |
| **正方全彩** | `logo_main_1x1.png` | 社群頭像、App icon、正方版位 |
| **主 Logo** | `logo_main.png` | 通用場景 |
| **黑色版** | `logo_black.png` | 淺色背景、單色印刷 |
| **含文字版** | `logo+字.png` | 需要品牌名稱露出的場景 |

### 2.2 Logo 安全距離

- Logo 四周保留至少 **Logo 高度 1/4** 的淨空區域
- 安全距離內不放置任何文字、圖形、裝飾

```
┌──────────────────────┐
│                      │
│    ┌──────────┐      │
│    │          │      │
│    │   LOGO   │ ← 安全距離 = Logo 高度 × 0.25
│    │          │      │
│    └──────────┘      │
│                      │
└──────────────────────┘
```

### 2.3 Logo 最小使用尺寸

| 場景 | 最小寬度 |
|------|---------|
| 螢幕顯示 | 80px |
| 印刷品 | 20mm |

### 2.4 Logo 禁止用法

- 不可拉伸、壓縮、旋轉
- 不可更改 Logo 顏色（僅限使用提供的版本）
- 不可在 Logo 上疊加文字或圖形
- 不可將 Logo 放在過於雜亂的背景上
- 不可使用低解析度的 Logo

### 2.5 待補齊項目

> **注意**：目前 Logo 僅有 PNG 格式。以下版本尚需製作：
> - AI / EPS 向量原始檔
> - SVG 格式（網頁用）
> - 反白版（深色背景用）
> - Icon-only 版（無文字）

## 4. 字體系統

### 4.1 字體選用

| 用途 | 字體 | 授權 | 取得方式 |
|------|------|------|---------|
| **英文** | Inter | SIL Open Font License（免費商用） | [Google Fonts](https://fonts.google.com/specimen/Inter) |
| **中文** | Noto Sans TC | SIL Open Font License（免費商用） | [Google Fonts](https://fonts.google.com/noto/specimen/Noto+Sans+TC) |
| **程式碼** | JetBrains Mono | SIL Open Font License（免費商用） | [JetBrains](https://www.jetbrains.com/lp/mono/) |

### 4.2 字級階層

| Token | 字級 | 行高 | 字重 | 用途 |
|-------|------|------|------|------|
| Display | 36px | 1.2 | 700 (Bold) | Hero 標題、主視覺大字 |
| H1 | 30px | 1.2 | 700 (Bold) | 頁面標題 |
| H2 | 24px | 1.3 | 600 (SemiBold) | 區塊標題 |
| H3 | 20px | 1.4 | 600 (SemiBold) | 小標題 |
| Body LG | 18px | 1.6 | 400 (Regular) | 重要段落 |
| Body MD | 16px | 1.5 | 400 (Regular) | 標準內文 |
| Body SM | 14px | 1.5 | 400 (Regular) | 小字說明 |
| Caption | 12px | 1.4 | 400 (Regular) | 標註、時間戳 |

### 4.3 字體使用規則

- 標題用 **Bold (700)** 或 **SemiBold (600)**，不用 Light / Thin
- 內文統一 **Regular (400)**，需要強調時用 **SemiBold (600)**
- 中英文混排時，英文使用 Inter、中文使用 Noto Sans TC，不混用其他字體
- 程式碼片段一律使用 JetBrains Mono

### 4.4 印刷品字體

- 印刷品同樣使用 Inter + Noto Sans TC
- 內文最小 9pt，標題建議 14pt 以上
- 行距建議 1.5 倍以上

## 5. 品牌語氣與文案規則

### 5.1 語氣定位

| 維度 | 方向 | 範例 |
|------|------|------|
| 正式度 | 專業但不官腔 | 「2 週交付 1 個可驗收作品」而非「本機構提供短期密集培訓方案」 |
| 溫度 | 溫暖但不油膩 | 「你會驚訝自己的產出速度」而非「改變人生就在今天！！！」 |
| 直接度 | 直接打痛點 | 「學了很多但交付不了，問題不在你不努力」 |
| 技術感 | 有深度但可理解 | 用具體數據與範例，不用空泛形容詞 |

### 5.2 文案基本規則

- **稱呼用戶**：「你」（非「您」、非「同學」）
- **按鈕動詞**：主動語態 — 「開始學習」「提交作品」「立即報名」
- **錯誤訊息**：先說發生什麼，再說怎麼修 — 「上傳失敗，請確認檔案小於 10MB」
- **空狀態**：鼓勵行動 — 「還沒有任何課程，立即探索」
- **語言**：繁體中文為主，技術術語保留英文（如 RAG、API、Sprint）

### 5.3 品牌常用語句

| 類型 | 語句 |
|------|------|
| **標語** | 不只學會，更要交付。 |
| **定位句** | 我們不賣課程，我們賣交付能力。 |
| **價值承諾** | 2 週交付 1 個可驗收作品。 |
| **信任建立** | 業界首創 Rubric 評分，透明可追溯。 |
| **CEO 宣言** | 讓每一個學習者，都能成為獨立思考、與 AI 協作的未來領導者。 |

### 5.4 文案禁忌

- 不使用「速成」「捷徑」「躺賺」「零基礎輕鬆上手」
- 不販賣焦慮：不用「再不學就來不及」「你的同齡人已經」
- 不做虛假承諾：不保證薪資漲幅、不保證錄取或轉職成功
- 不用浮誇感嘆號：「！！！」「???」

### 6.4 按鈕樣式

| 類型 | 背景 | 文字 | 用途 |
|------|------|------|------|
| Primary | `#2C918C` | `#FFFFFF` | 主要 CTA |

- 左右 padding：16px

- 背景：`#FFFFFF`（Light）/ `#0F0F0F`（Dark）
- 圓角：12px
- 邊框：1px solid `#E5E7EB`
- Hover：邊框變 `#2C918C`，上移 -2px
- 精選卡片：頂部 `#BA4D43` 光暈

## 7. 版面與間距系統

### 7.1 間距基準

所有間距為 **8px 的倍數**：

```
4px   — 極小（元素內部微距）
8px   — 小（元素間緊湊排列）
16px  — 標準（段落間距）
24px  — 中（區塊內間距）
32px  — 大（區塊間間距）
48px  — 特大（Section 間距）
64px  — 超大（Hero 與內容分隔）
```

### 7.2 RWD 斷點

| 裝置 | 寬度 | 欄數 | 左右 Padding |
|------|------|------|-------------|
| Mobile | < 768px | 1 欄 | 16px |
| Tablet | 768px - 1280px | 2 欄 | 24px |
| Desktop | > 1280px | 12 欄 | 32px |

- 最大內容寬度：1280px
- 欄間距：24px

### 7.3 簡報版面

| 項目 | 規格 |
|------|------|
| 比例 | 16:9 |
| 標題區 | 上方 1/3 |
| 內容區 | 下方 2/3 |
| 邊距 | 至少 40px |
| 每頁重點 | 最多 1 個核心訊息 |

## 9. 禁止事項

### 9.1 視覺禁止

- 不使用漸層彩虹色、霓虹色
- 不使用超過 3 種品牌色以外的顏色
- 不使用花俏的裝飾性字體
- 不使用低解析度圖片
- 不使用未授權的圖庫照片
- 不過度使用動畫效果

### 9.2 文案禁止

- 不暗示「速成」「捷徑」「輕鬆月入六位數」
- 不販賣焦慮
- 不做無法兌現的承諾
- 不使用浮誇的感嘆號或表情符號

### 9.3 Logo 禁止

- 不壓扁、拉伸、旋轉
- 不改色
- 不加外框、陰影、3D 效果
- 不放在無法辨識的背景上
