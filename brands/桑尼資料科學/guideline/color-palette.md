## 13. 印刷用 CMYK 快速參照表

> CMYK 值由 RGB 數學轉換而得。正式大量印刷前，建議以 Pantone 色票比對或輸出打樣校準。
> 印刷色域較螢幕窄，紫色系（Accent Purple、Violet）在 CMYK 印刷中會略顯暗沉，屬正常現象。

### 品牌核心四色（印刷必用）

| 色名 | HEX | CMYK (C, M, Y, K) | 印刷注意 |
|------|------|-------------------|---------|
| **Primary Teal** | `#2C918C` | `70, 0, 3, 43` | 主色，大面積使用穩定 |
| **Accent Purple** | `#A855F7` | `32, 66, 0, 3` | 紫色印刷色偏大，務必打樣 |
| **Featured Red** | `#BA4D43` | `0, 59, 64, 27` | 偏磚紅，印刷還原度高 |
| **Navy** | `#1E3A5F` | `68, 39, 0, 63` | 深色穩定，可替代純黑做標題 |

### 狀態色（印刷輔用）

| 色名 | HEX | CMYK (C, M, Y, K) |
|------|------|-------------------|
| Success Green | `#10B981` | `91, 0, 30, 27` |
| Warning Amber | `#F59E0B` | `0, 36, 96, 4` |
| Error Red | `#EF4444` | `0, 72, 72, 6` |
| Info Blue | `#3B82F6` | `76, 47, 0, 4` |

### 印刷安全提醒

- **螢幕色 ≠ 印刷色**：所有 CMYK 值皆為近似值，最終以印刷打樣為準
- **紫色警告**：`#A855F7` 和 `#8B5CF6` 在 CMYK 色域中衰減最嚴重，建議重要印刷物使用 Pantone 專色
- **深色背景印刷**：`#050505` 建議使用 Rich Black (`60, 40, 40, 100`) 而非四色黑
- **白色**：印刷中白色 = 不上墨 / 留白，非 CMYK 值
