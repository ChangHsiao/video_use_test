## 二、推動句（Push Line）

> 放在 CTA 按鈕上方或正文結尾，推動讀者採取行動的一句話。

### 「只差一步」型

| 語句 | 適用場景 |
|------|---------|
| 你離「用 AI 做出東西」只差這一天。 | AI Coding 工作坊 |
| 你離十倍生產力，只差這一天。 | AI 槓桿力工作坊 |
| 你離「用 AI 做出東西」只差按下播放鍵。 | 線上課程 |
| 2 週後，帶走你的作品。 | Sprint Camp 招生 |
| 選擇你的垂直領域 → 選擇票種 → 2 週後，帶走你的作品。 | Sprint Camp 步驟引導 |

### 「與其...不如」型

| 語句 | 適用場景 |
|------|---------|
| 與其花三個月自學寫程式，不如花一天學會指揮 AI。 | AI Coding 工作坊 |
| 與其花三個月自己摸索，不如花一天學會系統化的 AI 槓桿方法論。 | AI 槓桿力工作坊 |
| 與其花三個月自學寫程式，不如跟著這堂課，從零到完成兩個可運作的 AI 作品。 | 線上課程 |

### 「痛點對比」型

| 語句 | 適用場景 |
|------|---------|
| 同樣用 AI，有人省 3 小時，有人多花 3 小時。差別就在提示詞。 | 提示詞工作坊 |
| 同樣的問題被問 100 遍，你要回答 100 遍嗎？ | n8n 自動化工作坊 |
| 做一個 LINE AI 助理，讓它 24 小時幫你回答。你只需要花一天學會怎麼做。 | n8n 自動化工作坊 |
| AI 不會取代你，但會用 AI 的人會取代你。 | AI 槓桿力工作坊 |

## 九、CTA 選用指南

### 依轉換目標選擇

```
想要什麼？
├── 直接付費報名 → 「立即報名搶位」+「早鳥價」+ 限額
├── 收集 Email → 「免費下載 AI 學習指南」+ 信任句
├── 預約諮詢 → 「30 分鐘免費諮詢」
├── 導流到課程頁 → 「瀏覽課程 →」「了解更多」
└── 社群互動 → 「報名連結在 bio」「留言 +1」
```

### 依語氣強度選擇

```
弱 ─────────────────────────────────── 強

了解更多 → 瀏覽課程 → 開始學習 → 立即報名 → 立即報名搶位
                                              ↑
                                         加上限額 + 早鳥
                                         = 最強組合
```

### 最強 CTA 組合公式

```
[痛點對比句]
+
[推動句：你離 X 只差這一天]
+
[價格：早鳥價 + 原價刪除線]
+
[按鈕：立即報名搶位]
+
[信任句：限額 XX 人 / 不滿意退費]
```

## 十、CTA 禁止用法

與品牌語氣規範一致，以下 CTA 風格禁止使用：

| 禁止 | 原因 |
|------|------|
| 「再不學就來不及了！！！」 | 販賣焦慮 |
| 「月入六位數不是夢」 | 虛假承諾 |
| 「限時 3 小時！！！」 | 過度急迫（除非確實如此） |
| 「改變人生就在今天！」 | 空洞口號 |
| 「零基礎也能輕鬆上手」 | 與品牌定位衝突 |
