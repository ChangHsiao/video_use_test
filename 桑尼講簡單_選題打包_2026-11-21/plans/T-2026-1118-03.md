## 一句承諾

看完知道 USB-C 線為什麼長一樣能力卻差很多，以及下次買線、拿起抽屜裡的線時，三秒判斷它能做什麼

## 開場鉤子

- **畫面**：關鍵畫面：俯拍桌面兩條白色 USB-C 線並排，手指輪流指；切分割畫面——同一個大檔案的複製進度條，左邊快速跑完、右邊緩慢前進（依實測）；最後特寫剪刀剪開兩條報廢線的斷面，芯線數量明顯不同（依實拆）。
- **口白**：口白：『這兩條線，長得一模一樣、插頭一模一樣。可是同一個檔案，一條幾秒就傳完，另一條要等好幾分鐘。差在哪？我們把它剪開來看。』

## 摘要

從兩條外觀相同的 USB-C 線傳同一個檔案、速度天差地遠開場，用『門 vs 路』說明 USB-C 只統一接頭不統一能力；剪開報廢線比較芯線，再拆解資料速度（USB 2.0 480Mbps vs 10／40Gbps）、電力（60W／240W 與 E-Marker）、影像三件事，引用 Apple『隨附線只支援 USB 2』與 USB-IF 標誌規範，最後給三招看線與買線清單。

## 五面向企劃

### 1. 主題與核心問題

- **談誰／什麼**：談 USB-C『接頭』與『線材能力』是兩回事：USB-C 只規定接頭形狀，線裡面有沒有高速資料線、能扛多少電流、有沒有 E-Marker 晶片，各條線都不一樣。USB-IF《E-Marker Testing》（已讀）：USB-C 對 USB-C 線都需要 E-Marker，唯一例外是『只有 USB 2.0、3A』的線；UL Solutions（已讀）：新版規範下 USB-C 線額定只有 60W 或 240W 兩種，240W（EPR）必須有 E-Marker；USB-IF 線材標誌指引（2024-09-03，已讀）：通過認證的 C to C 線須在接頭外殼標示速度與瓦數，USB 2.0 的 60W／240W 線不標資料速度。Apple（已讀）：USB-C Charge Cable 只有 480Mbps、不支援影像；Thunderbolt 4 Pro Cable 可到 40Gbps、100W，接頭上有閃電標誌。
- **最想解釋**：最想解釋：USB-C 是『門的形狀』，不是『路有多寬』——同一個門後面，可能是一條只能走 480Mbps 的小路，也可能是 40Gbps 的高速公路；能扛多少瓦，則看線裡的電線粗細與那顆會『自我介紹』的 E-Marker 晶片。整條路的速度，由最弱的一環決定。
- **主張**：影片主張：USB-C 統一的是接頭，不是能力；看懂『資料、電力、影像』三件事各自看什麼，再看線上的標誌，就不會再買錯線、也不會誤會手機或筆電壞掉。
- **研究方向**：研究方向：USB-IF《USB Type-C Cable Logo Usage Guidelines》（2024-09-03 PDF，已讀：C to C 線須在 overmold 標示速度／瓦數標誌；20Gbps＋20V 3A 線須標 20Gbps/60W；USB 2.0 60W／240W 線不標資料速度）；USB-IF《Cable Power Rating Logo Usage Guidelines》（2022-02 PDF，已讀摘要：240W 標誌須通過 PD 3.1 EPR 測試並列入 Integrators List）；USB-IF《E-Marker Testing Methodology Rev1.2》（已讀：除 USB 2.0 only 3A 線外，C to C 線都須有 E-Marker）；UL Solutions《240W USB-C Cable Performance Testing》（已讀：只有 60W／240W 兩種額定、EPR 須 E-Marker、建議防電弧）；Apple 支援 118204（2024-11-08，已讀：Charge Cable 480Mbps 無影像；TB4 Pro 40Gbps／100W；TB5 Pro 120Gbps／240W；閃電標誌）；Apple 支援 105099（2026-10-22，已讀：iPhone 15 起 USB-C、隨附線只支援 USB 2、Pro 機型配 USB 3 線可到 10Gbps、接螢幕需 USB 3.1 以上線）；Wikipedia USB-C；YouTube：Andreas Spiess《#475 USB-C Tutorial for Everybody》（2024-01-21，26:07）、ChargerLAB《Teardown of EcoFlow 240W USB4 Cable》（2026-02-24，5:18）、GadgetGang HK《USB-C 線 全面解說》（2026-02-18，14:05，粵語）、Rouben Cherchian《USB-C Cable Types Explained》（2025-08-02，8:01）、DPReview TV《USB Power Explained》（2021-12-01，12:17）作結構參考。
- **故事主線**：故事主線：桌上排 4 條外觀相似的 USB-C 線（手機隨附線、便宜充電線、USB 3 線、Thunderbolt／USB4 線，實際組合依手邊為準）→ 同一個大檔案從手機／隨身硬碟複製到電腦，用不同線計時（依實測）→ 有的幾秒、有的要好幾分鐘 →『線不是都一樣嗎？』→ 第一層：接頭 vs 線材——門 vs 路的比喻 → 第二層：拆給你看——剪開兩條報廢線（安全處理）比較裡面的芯線數量（依實拆）＋示意圖：USB 2.0 只有一對資料線、高速線多了好幾對 → 第三層：電力——60W 與 240W、E-Marker 晶片會跟充電器『自我介紹』（USB 測試器讀取畫面，若有）→ 第四層：影像——為什麼有的線接螢幕沒畫面（Apple 原文：Charge Cable 不支援影像）→ 第五層：怎麼看——USB-IF 標誌、閃電標誌、包裝規格三招；最弱一環原則 → 收束：買線清單。
- **核心問題**：USB-C 線明明長得一模一樣，為什麼有的充筆電很慢、有的傳照片要等半天、有的接螢幕完全沒畫面？買線的時候到底要看什麼？

### 2. 觀眾與先備知識

- **給誰**：一般大眾（換了 USB-C 手機、筆電充電慢、接螢幕失敗、抽屜裡一堆線分不清的人）；次要：創作者與學生（常傳大檔案、接外接螢幕）。
- **先備知識**：先備：用過 USB-C 線即可；不需要懂電子學（以『門 vs 路』『水管粗細』比喻補上）。
- **解釋深度**：解釋深度：只講資料速度（USB 2.0 480Mbps vs 10／40Gbps）、電力（60W vs 240W、E-Marker）、影像（DisplayPort Alt Mode 一句帶過）、標誌四件事；術語 USB-C、USB 2.0／USB 3／USB4、Thunderbolt、E-Marker、Gbps、W（瓦）保留附中文；不講 PD 協商細節、針腳定義表、USB 命名演變史（只一張圖帶過）。
- **痛點**：筆電用手機線充電很慢或不充；傳影片到電腦要等很久；接螢幕沒畫面以為壞掉；抽屜一堆線分不清；網購線材規格看不懂、怕買到不安全的線
- **開場鉤子風格**：開場鉤子：兩條外觀幾乎一樣的白色 USB-C 線並排特寫 → 同一個檔案同時開始複製，左邊進度條瞬間跑完、右邊龜速（依實測）→ 字卡『長一樣，差幾十倍？』

### 3. 觀看後的改變

- **理解**：理解：USB-C 是接頭標準，線材能力分資料、電力、影像三項各自不同；手機隨附線常只有 USB 2.0 速度；超過 60W 的線需要 E-Marker；整條鏈路速度由最慢的一環（手機、線、電腦、硬碟）決定。
- **重新思考**：重新思考：『統一接頭』解決了插不插得進去，沒有解決能力透明——工程師觀點：相容性設計常把複雜度藏到使用者看不到的地方，所以標示與規格才是關鍵；遇到『慢』先懷疑最弱的一環，而不是整台機器。
- **行動**：行動：買線看三項——資料速度（Gbps）、瓦數（60W／240W）、是否支援影像；認 USB-IF 認證標誌或 Thunderbolt 閃電；把家裡的線用標籤分『充電用／高速用』；傳大檔或接螢幕時換高速線；不買來路不明、無標示的高瓦數線。
- **段落目的**：複製檔案計時 Hook（反直覺）→門 vs 路比喻（核心概念）→剪線看芯線（拆給你看主體）→60W／240W 與 E-Marker（電力）→接螢幕沒畫面（影像）→三招看標誌＋最弱一環（判斷方法）→買線清單＋收束（行動＋品牌記憶）。
