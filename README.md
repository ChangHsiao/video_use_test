# 科普短片 skill

把發表會、講座、訪談等影片，做成 2 分半的直式科普短片。給素材，回答 5 個問題。

Claude 會讀完素材、挑主題、寫旁白稿、排分鏡、做說明動畫、上中英字幕。風格、長度、節奏都有預設值，你只在關鍵的地方做決定。

## 需要

| 項目 | 用途 | 費用 |
|---|---|---|
| [Claude Code](https://code.claude.com/docs/en/setup) | 執行這個 skill | Claude Pro 以上 |
| [ElevenLabs](https://elevenlabs.io) | 轉錄、配音 | 免費方案每月約可轉錄 30 分鐘；配音要在網站上手動生成 |
| [Node.js](https://nodejs.org) | 說明動畫（Remotion） | 免費；Remotion 4 人以上的公司要買授權 |

## 安裝

把這段話貼給 Claude Code：

```text
幫我安裝 https://github.com/ChangHsiao/video_use_test 。先讀 install.md 完成安裝：下載這個 repo、設定 ffmpeg、把 skill 註冊到你正在用的 agent、設定 ElevenLabs API key（需要時請我貼給你）。接著讀 SKILL.md 了解怎麼用，helpers/ 裡是剪輯用的程式。裝好之後不要自己轉錄，告訴我裝好了，等我給素材。
```

手動安裝見 [install.md](install.md)。

## 使用

把素材放進一個新資料夾，在那裡打開 Claude Code，說：

> 做一支科普短片

一支片用一個資料夾。轉錄、配音、生成講者會花額度，Claude 會先問過你。

過程中它會停下來 5 次：

| 時機 | 你會看到 | 你要決定 |
|---|---|---|
| 開始 | 素材清單 | 有沒有漏、逐字稿怎麼取得 |
| 讀完素材 | 企劃：主題、標題、大綱、風格 | 照推薦做，或指定要換的項目；要不要講者、用哪個配音聲音 |
| 寫完稿子 | 稿子和分鏡表 | 要改的句子和畫面 |
| 合成之前 | 樣張和 10～15 秒樣片 | 要改哪一張 |
| 完成 | 成品和品質檢查結果 | 修改意見 |

所有產出放在素材資料夾的 `edit/`：內容目錄、企劃、旁白稿（每句附原片出處）、分鏡表、字幕和影片。

只使用你有權使用的素材，公開發布前先確認授權。

## 目前狀態

2026 年 11 月。

- 從素材到分鏡表，每一步都有寫好的做法；配音到成品只定了要交出什麼，做法由 Claude 判斷，測試時做到預覽影片
- 說明動畫只在 Linux（WSL）測過
- 手動生成的配音沒有逐字時間，字幕時間從停頓推算，不確定的句子會列出來請你檢查
- 目前只有一種畫面風格（暗色科技風）
- 價格和方案以各服務官網為準
